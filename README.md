# Corporate Expense & Budget Variance Tracker

An advanced, automated Excel-based financial tool designed to monitor operational expenses, analyze budget variances, and ensure rigorous financial record integrity.

## 📊 Project Overview
The **Corporate Expense & Budget Variance Tracker** is a financial operations and MIS reporting workbook built to track actual spending against allocated budgets. By leveraging automated lookup formulas, dynamic summary tables, and visual conditional formatting, this project eliminates manual calculation errors and provides instant visibility into financial performance and spending anomalies.

## 🚀 Key Features
- **Automated Expense Logging:** Structured financial ledger for recording transaction dates, expense categories, departments, and monetary amounts.
- **Budget Variance Analysis:** Real-time calculation of variances ($\text{Variance} = \text{Actual} - \text{Budget}$) to flag overspending or underspending across operational categories.
- **Dynamic Summaries & MIS Reporting:** Aggregated reporting tables using advanced lookup and conditional logic to support financial auditing.
- **Visual Alerting:** Automated conditional formatting rules that highlight cost overruns and budgetary risks instantly.

## 🛠️ Excel Tools & Techniques Used
- **Formulas & Functions:** `SUMIF`, `SUMIFS`, `XLOOKUP`, nested `IF` statements, and arithmetic variance formulas.
- **Data Analysis & Organization:** Pivot Tables, Data Validation dropdowns, and structured range references.
- **Data Formatting:** Conditional Formatting rules for variance thresholds and clean executive-ready typography.
